# Primer Parcial - Programación Web II: API REST de Productos

API RESTful desarrollada con Node.js, Express y Sequelize ORM, conectada a Microsoft SQL Server.

## Tecnologías Utilizadas
- **Entorno:** Node.js
- **Framework:** Express.js
- **ORM:** Sequelize
- **Driver de BD:** msnodesqlv8 (Windows Authentication)
- **Base de Datos:** Microsoft SQL Server
- **Herramienta de pruebas:** Postman
